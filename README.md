## Usage

Run the `./moar_dots.sh` script from the repo root. Use the `-i` (install) option to set up dotfiles and dependencies, `-r` (restore) to restore from a backup, or `-u` (uninstall) to remove an existing install. Pass `-h` or `--help` to see all options.
